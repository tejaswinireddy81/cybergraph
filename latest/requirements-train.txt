# Pinned, reproducible environment for (re)training the models.
#
# Why this exists: the live-pipeline pickles (ae_model, fusion_model, scaler, graph_feature_scaler,
# gnn_scalers) were saved with scikit-learn 1.8.0, while the legacy rf_model.pkl was saved with 1.9.0
# (detected from the warnings sklearn raises while unpickling; see scripts/preflight_retrain.py).
# Pickles are only guaranteed to load under the version that wrote them, so training and serving
# must use ONE pinned set.
#
# These are the versions the current test-suite and models were verified with
# (Python 3.14 / Windows). On another Python version, re-resolve and re-run
# `python scripts/preflight_retrain.py` before training.
#
#   python -m venv .venv-train
#   .venv-train\Scripts\activate          (Linux/macOS: source .venv-train/bin/activate)
#   pip install -r requirements-train.txt
#   python scripts/preflight_retrain.py   # read-only checks; nothing is trained or overwritten
#
# TensorFlow is intentionally absent: the live pipeline (train_xgboost_ae.py, train_gnn.py,
# train_temporal_gnn.py) does not use it. Only the legacy RF/Keras scripts do.
